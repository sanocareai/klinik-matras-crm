# Daftar istilah (Bahasa Indonesia)

| Istilah di layar | Artinya |
|---|---|
| **Unit** / **Unit 360** | Satu kasur dalam satu order; Unit 360 = halaman lengkap satu unit (identitas, proses, bahan, QC, dokumentasi, riwayat) |
| **Layanan Sales** | Yang **dijual** Sales ke pelanggan (mis. *Ganti Kain*). Berbeda dari layanan teknis hasil diagnosa |
| **Layanan Teknis** | Pekerjaan hasil **Diagnosa** di bengkel (hanya di kartu Status/QC) |
| **Ganti Kain** | Layanan ganti permukaan kain; **krusial** — kain/warna harus persis permintaan customer |
| **Catatan Sales** / **Request khusus** | Permintaan/keluhan pelanggan yang ditulis Sales |
| **Backlog / Belum Dijadwalkan** | Unit yang belum punya meja & tanggal |
| **Meja 1–4** | Tempat kerja bongkar; **maks. 3 unit per meja**, target 12 unit/hari |
| **Urutan** | Urutan pengerjaan di satu meja; **urutan manual selalu menang** |
| **Prioritas** | Normal · Tinggi · Mendesak (nilai tetap dari sistem; **Terlambat** adalah label terpisah) |
| **12/12** | Semua 12 tahap selesai — kartu terkunci di dasar meja |
| **PIC usulan** | Operator yang *diusulkan* sebelum unit dijadwalkan — belum final |
| **Handle ⋮⋮** | Pegangan untuk menyeret kartu (tahan lalu seret) |
| **Tahap 1–12** | 1 Sebelum Bongkar · 2 Uji Rasa Awal · 3 Hasil Bongkar & Material Lama · 4 Uji Fondasi Lama · 5 Diagnosa Teknis · 6 Fondasi Baru · 7 Lapisan Baru · 8 Uji Tekstur Akhir · 9 Kirim ke Corner · 10 Mulai Jahit · 11 Jahit Selesai · 12 Konfirmasi Selesai |
| **Diagnosa / BOM** | Temuan teknis + daftar bahan yang akan dipakai (*Planned BOM*) |
| **Reservasi bahan** | Bahan disisihkan untuk unit; stok **belum** berkurang |
| **Serah bahan / Pick** | Bahan benar-benar diserahkan; stok berkurang |
| **Menunggu Bahan Baku** | Laporan kekurangan bahan dari Operator ke Gudang (pekerjaan dijeda) |
| **QC PASS / FAIL**; **Rework** | Lulus / tidak lulus uji; rework = pengulangan tahap yang ditunjuk QC |
| **Retur sisa** | Sisa bahan yang dikembalikan ke Gudang setelah tahap 12 |
| **Barang jadi** | Kasur selesai yang diserahkan Corner ke Gudang |
| **Tertahan** | Barang jadi belum bisa diterima karena retur sisa belum selesai |
| **Draf offline** | Foto yang disimpan di HP saat tanpa sinyal, lalu terkirim otomatis |
| **Mode Demo** | Data contoh read-only untuk Admin/Owner — **bukan** latihan kerja, tidak menyimpan apa pun |
| **Staging latihan** | Aplikasi salinan khusus latihan; data fiktif **QA-PV2** |

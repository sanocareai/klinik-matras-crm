# Checklist 1 halaman — PIC Corner

**Mulai kerja**
- [ ] Masuk → **Aplikasi Corner** (antrean kosong = belum ada unit lolos QC & tahap 9 — bukan error)
- [ ] Kode unit cocok dengan kasur di meja jahit
- [ ] Baca **Layanan Sales** + **Request khusus**

**Ganti Kain (WAJIB sebelum menjahit)**
- [ ] Kotak oranye dibaca
- [ ] **Jenis kain, warna kain, warna list, resleting** = catatan Sales
- [ ] Catatan kosong / ragu → **berhenti**, tanya Production Lead

**Tahap 10 — Mulai Jahit**
- [ ] Model (Biasa / Plushtop / Pillowtop) benar
- [ ] Spesifikasi kain & warna list diisi persis pesanan

**Tahap 11 — Kirim Bukti Jahit**
- [ ] Jahitan rapi & kuat · list rata · resleting berfungsi · kasur bersih
- [ ] Foto (+ video) jelas

**Tahap 12 — Konfirmasi Selesai**
- [ ] Kasur benar-benar selesai & terbungkus · foto
- [ ] Setelah kirim: unit *Menunggu Gudang* — **selesai bagian Anda**

**Jika unit tampil "tertahan retur"** → bukan urusan Corner (Gudang menerima retur sisa).

**Berhenti & minta bantuan bila:** kain tidak cocok dengan catatan · barang jadi ditolak Gudang · pesan sama 3× setelah muat ulang.

**Selesai shift:** [ ] keluar (nama → **Keluar**)

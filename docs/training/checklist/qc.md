# Checklist 1 halaman — QC

**Mulai**
- [ ] Masuk → **Quality Control** → tab **Menunggu QC**
- [ ] Buka kartu (atau **Unit 360**) → lihat bukti tahap 1–8, terutama **Uji Tekstur Akhir**

**Periksa**
- [ ] Hasil uji (Pas / Terlalu Keras / Terlalu Empuk) masuk akal untuk **berat badan** pelanggan
- [ ] Ganti Kain: kain & warna sesuai catatan Sales

**PASS**
- [ ] Berat acuan diisi · kecocokan *Pas*
- [ ] **Foto QC ada (wajib)**
- [ ] Simpan Putusan

**FAIL**
- [ ] Tab **FAIL** · **temuan ditulis (wajib)**
- [ ] **Tahap rework** dipilih
- [ ] **Foto ada (wajib)**
- [ ] Simpan — unit kembali ke Operator Meja (**Ulangi … (Rework)**)
- [ ] Unit muncul lagi setelah rework → periksa ulang → putuskan

**Larangan bypass**
- [ ] Tidak meminta/menerima "loloskan saja"
- [ ] Tidak mengerjakan tahap produksi (sistem menolak)
- [ ] Ragu = **FAIL dengan alasan** atau tanya Production Lead
- [ ] Putusan tidak diubah sendiri — koreksi lewat Production Lead

**Konflik:** *"sudah diputuskan / revisi berubah"* → muat ulang → cek putusan terakhir → **jangan putuskan dua kali**.

**Selesai:** [ ] keluar (nama → **Keluar**)

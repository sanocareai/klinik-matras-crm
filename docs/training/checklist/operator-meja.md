# Checklist 1 halaman — Operator Meja

**Mulai kerja**
- [ ] Masuk → **Aplikasi Meja** → kartu aktif tampil
- [ ] Kode unit & pelanggan **cocok dengan kasur di meja**
- [ ] Baca **Layanan Sales** dan **Request khusus**
- [ ] **Ganti Kain?** kotak oranye dibaca. *"Catatan kain belum tersedia"* → **berhenti, tanya Production Lead**

**Setiap tahap**
- [ ] Tekan tombol biru **Tindakan berikutnya**
- [ ] Isi formulir; foto/video **sesuai aturan tahap** (tahap bertanda wajib video)
- [ ] **Kirim** → tunggu centang hijau → kartu pindah tahap
- [ ] Sinyal putus: **Coba Lagi** — jangan isi ulang dari nol

**Diagnosa (tahap 5)**
- [ ] Temuan jelas · layanan teknis dipilih · bahan + qty benar
- [ ] Bahan kurang? tekan **Menunggu Bahan Baku** — **jangan lanjut** sebelum bahan diserahkan

**Setelah QC gagal**
- [ ] Baca alasan QC di kartu (**Ulangi … (Rework)**)
- [ ] Ulangi tahap yang ditunjuk · kirim bukti baru · bahan tambahan lewat Production Lead
- [ ] Setelah Uji Tekstur Akhir: kartu *menunggu QC* — itu giliran QC

**Tahap 9 — Kirim ke Corner**
- [ ] Hanya setelah QC **PASS** · foto kasur siap dibungkus

**Jangan:** menyelesaikan tahap tanpa mengerjakannya · mengirim foto unit lain · mengerjakan unit di luar antrean · menebak jika layar menyuruh menunggu.

**Selesai shift:** [ ] tidak ada kartu menggantung tanpa laporan · [ ] keluar (nama → **Keluar**)

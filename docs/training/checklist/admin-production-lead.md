# Checklist 1 halaman — Admin / Production Lead

**Setiap pagi (5 menit)**
- [ ] Masuk → Portal → pilih **Production Operations**
- [ ] **Ringkasan**: terlambat? menunggu bahan? menunggu QC?
- [ ] **Status Produksi**: ada unit macet di satu kolom? kolom *Dalam Perjalanan* sudah dikonfirmasi tiba?
- [ ] **Rencana Produksi**: backlog terurut Mendesak → Tinggi → Normal; Meja 1–4 terisi ≤ 3

**Menjadwalkan satu unit**
- [ ] Baca kartu: **Layanan Sales**, **Kasur**, **Catatan Sales**
- [ ] **Ganti Kain?** garis & kotak **oranye** dibaca; catatan kain ada (kalau tidak → tanya Sales dulu)
- [ ] Pilih prioritas yang benar
- [ ] Seret lewat **⋮⋮** *atau* tombol **Jadwalkan / Pindahkan**
- [ ] Tunggu *Menyimpan…* selesai — kartu pindah **setelah** server menjawab
- [ ] Meja penuh / revisi basi? → muat ulang → ulangi sekali

**Urutan di meja**
- [ ] Urutan manual (▲▼ / seret) **selalu menang** — sistem tidak mengurutkan ulang
- [ ] Peringatan oranye *Mendesak di bawah Normal* → putuskan sendiri
- [ ] Unit **12/12** terkunci di bawah — jangan dicoba dipindah

**Sebelum pulang**
- [ ] Tidak ada unit *Mendesak/Tinggi* belum dijadwalkan
- [ ] Tidak ada *Menunggu Bahan* yang belum dihubungi ke Gudang
- [ ] Keluar (nama Anda → **Keluar**)

**Berhenti & minta bantuan bila:** data tampak salah unit · pesan sama 3× setelah muat ulang · harga/data pelanggan nyata muncul di latihan.
